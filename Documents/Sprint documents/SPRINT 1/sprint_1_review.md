# Sprint 1 review report

## Sprint Goal

The goal of this sprint is to establish a project team, select a project topic, 
define the product vision and project plan, and set up project management tools 
along with the initial product backlog.

## Completed User Stories / Tasks

- Created a project team and selected a project topic as a note taking application, and named it Glowstone.
- Set up a GitHub repository for code management and collaboration.
- Created a Trello workspace for project planning and tracking. [Link to Trello](https://trello.com/b/xQvpwM4z/sep1glowstone)
- Defined the product vision, including problem statement, target audience, value proposition, goals, and vision statement.
- Discussed and finalized user stories in Trello.
- Developed a UI blueprint for the application in Figma, prototype found in the Github page Documents → Images → Glowstone_prototype.png
- Defined the project plan document.

## Demo Summary

During the sprint review meeting, we presented the project setup, including the GitHub repository and Trello board. 
We showcased the defined project vision and project plan. Additionally, showed UI prototype created in Figma.

## What Went Well
- Started planning early
- Got the necessary tasks done on time
- Group has a clear understanding of the project, and what needs to be done
- Created a comprehensive list of tasks

## What Could Be Improved

- More regular meetings
