## Sprint 7
During this sprint, our group focused on testing and evaluation.
We used SonarCube to generate a report, various plugin tools to help with finding and identifying issues,
then made heuristic evaluation report and user acceptance testing.

No functional changes were made.

### Functional Task Details:
During this sprint we identified a few issues, as listed in [the bug tracking table.](../../Reports/BugTracking.md)
Of these issues we were able to fix the critical issues involving database and code miscommunication, but haven't been able to fix either
of the Xming related issues due to our unfamiliarity with the tools. 

### Non-functional Task Details:
Test results came back mainly positive, with issues pointing towards the miscommunication between the database and the code and the long known
issue with Xming visual bugs. We fixed the functional issues, and made small improvements.

We made a user acceptance test document to test out specific user actions. Results were mainly positive.
Heuristic evaluation report can be seen [in the heuristic evaluation Excel sheet.](../../Reports/Heuristic_evaluation.xlsx)
